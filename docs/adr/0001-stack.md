# ADR-0001: Стек прототипа

Дата: 2026-11-07 · Статус: принято

## Контекст
Прототип для сбора данных исследования (сроки: недели). Команда: агенты + 1 ревьюер.
Требования: мобильный веб из QR, REST-подобный API, аналитика воронки, деплой на VPS через неделю.

## Решение
- Backend: **Go 1.22+**, stdlib `net/http` (ServeMux с методом+паттерном), `pgx/v5`, миграции **goose** (SQL).
- БД: **PostgreSQL 16** (выбор заказчика разработки; через docker compose).
- Frontend: **Vite + React 18 + TypeScript**, без UI-китов, стили на CSS-переменных.
- Инфра: **docker compose** (db + backend; backend раздаёт собранную статику фронта).

## Обоснование
- Go: статическая типизация, один бинарник, дешёвый деплой на VPS, минимум зависимостей.
- stdlib вместо echo/gin: API маленький (≈10 эндпоинтов), лишний фреймворк = лишняя поверхность.
- React: карточки/ленты/состояния — компонентная модель оправдана; Vite — самый быстрый старт.
- Без UI-китов: стиль жёстко привязан к сайту ресторана (UI-01…03), киты только мешают.

## Последствия
- Все зависимости фиксируются в go.mod/package.json; новые — только с обоснованием.
- Дев: только vite-proxy (/api → :8080), cookie проходит same-origin; CORS-механизм в проекте
  отсутствует, кросс-доменные запросы не поддерживаются.
