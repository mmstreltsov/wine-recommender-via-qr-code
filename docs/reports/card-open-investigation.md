# Открытие карточки: диагностика и QA

**Статус:** исправление проверено в изолированном окружении и развёрнуто на
локальном стенде; пользователь подтвердил, что теперь всё работает. Причина
конкретного пользовательского случая не установлена.

## Наблюдения и гипотеза

По предоставленной аналитиком агрегированной сводке HAR: 227 запросов за примерно
32,5 секунды; пять пар запросов блюда и рекомендаций завершились с HTTP 200 за
3–5 мс, ответов HTTP 4xx/5xx не было. Из 227 запросов 174 приходились на
изображения, до 96 интервалов загрузки пересекались. HAR не доказывает загрузку
CPU, отсутствие нажатий или наличие ошибок JavaScript.

Гипотеза: сохранение состояния истории при каждой прокрутке могло заблокировать
переход по ссылке при исключении `replaceState`. До исправления такой сценарий
воспроизведён контролируемой имитацией `SecurityError`, но связь с пользовательским
случаем не доказана.

## Исправление

- Переход больше не зависит от успешного `replaceState` родительской страницы.
- Сохранение положения прокрутки ограничено интервалом 250 мс и безопасно
  обрабатывает ошибку; размер кеша ограничен.
- Прокрутка и статус загрузки показываются сразу; источник события сохраняется
  при обычном сценарии.

## Проверки и ограничения

- По предоставленным результатам: frontend, 147 тестов, lint и build: PASS.
- Изолированный Chromium с mock API, размеры 375 и 1440: 24 проверки PASS,
  включая постоянный отказ `replaceState` и открытие одним нажатием. Реальный
  backend и физические устройства в этом прогоне не использовались.
- По предоставленному результату статического security-review: PASS,
  CRITICAL/HIGH/MED/LOW 0/0/0/0.
- При постоянном отказе History API `pushState` возможен полный переход с потерей
  атрибуции; безопасный возврат назад через полную навигацию может потерять
  состояние родительской страницы.
- Прежний дефект перехода вперёд при отсутствии Navigation API сохраняется.
  Физические Safari/iOS и Android, а также реальный путь гостя не проверены.

Локальный стенд пересобран без удаления БД и volumes; smoke-проверка прошла.
Результаты не доказывают устранение причины конкретного пользовательского случая.
