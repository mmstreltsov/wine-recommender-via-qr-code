**Статус: M4 реализована, но НЕ закрыта.** По решению пользователя оставшиеся проверки отложены ради фиксации текущего состояния в git. Этот отчёт не означает приёмку; `docs/10-requirements.md` не помечает M4 принятой. Результаты ниже переданы координатором и агентами; при подготовке checkpoint проверки не запускались.

## Реализовано

- Frontend на React 18: все экраны и состояния ошибок, тема, шесть локально размещённых шрифтов с OFL, отображение валюты.
- Bootstrap и барьер отправки событий; общее состояние корзины, доступности позиций и заглушки оплаты.
- Сохранение исходного Host при проксировании.
- Backend: белый список полей payload событий, проверки Origin и Content-Type, проверка EOF после JSON.
